Notion Calendar Sync

A personal, self-hosted integration operated by Julio Morales that synchronizes selected Notion calendar database entries and Google Calendar events in both directions.

The Python service runs on the account owner's Raspberry Pi. It uses the official Notion and Google Calendar APIs, stores synchronization state in SQLite, and supports polling, conflict review, and optional authenticated change notifications. It is not a hosted service accepting public registrations.

Google authorization requests permission to view and edit calendar events and to read the calendar list. The service configuration selects which calendars participate; the OAuth grant itself can cover all calendars accessible to the account. Attendee invitations and RSVP management are excluded by default.
