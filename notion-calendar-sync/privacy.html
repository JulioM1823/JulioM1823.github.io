Notion Calendar Sync

Privacy and data handling

Effective October 30, 2026. This notice describes the personal, self-hosted Notion Calendar Sync deployment operated by Julio Morales. Other self-hosted deployments are controlled by their respective operators.

Data accessed and purpose

The service reads the Google calendar list and event data returned by the Calendar API, and the configured Notion database properties. These can include titles, descriptions, notes, locations, dates, time zones, recurrence information, identifiers, links, and provider metadata. It uses these data to identify corresponding records, synchronize configured fields, detect conflicting edits, and recover from failures.

Data transfer and sharing

Configured event fields are sent between the account owner's Google Calendar and Notion workspace as required for synchronization. API traffic uses HTTPS. Normal service operation does not send calendar or Notion content to an AI model, advertising service, or analytics service. Data are not sold or used for advertising, profiling, or model training. Google user data are used only to provide the requested synchronization and recovery features, consistent with the Google API Services User Data Policy, including its Limited Use requirements.

Storage and security

OAuth access and refresh tokens, the Notion credential, item mappings, provider observations, pending operations, and conflict snapshots are stored on the operator's Raspberry Pi. Credential files and the synchronization database use restricted filesystem permissions. The operator controls the device and any backups. Ordinary application logs exclude tokens and event content; explicitly requested administrative conflict reports contain retained event values.

Retention and control

Mappings, conflict snapshots, and operation history can remain until the operator deletes the local state and backups. Removing an event does not necessarily remove its synchronization history. Revoking authorization stops further authorized API access but does not automatically erase copies already stored on the Pi, in backups, or on the other synchronized provider. Google access can be revoked in Google Account connections; Notion access can be removed in the workspace's connection settings. The operator can stop or uninstall the service and separately remove its local data and backups.
