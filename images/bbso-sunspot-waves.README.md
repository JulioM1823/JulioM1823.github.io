The movie shows observed intensity structures associated with sunspot waves.
It is not a numerical simulation, an AI-generated animation, a Doppler velocity
map, or a measurement establishing atmospheric gravity waves. The related study
also used SDO and IRIS; this individual movie is credited to BBSO/Zhao et al.

## Presentation processing

- Coalesced the original 17 GIF frames, preserving their chronological order.
- Removed the final frame's extra 900 ms hold; every frame lasts 100 ms.
- Cropped 12 pixels from each edge: 472 x 472 to 448 x 448. This removes edge
  artifacts; no spatial detail has been synthesized or upscaled in the files.
- Converted the existing color rendering to grayscale.
- Encoded H.264 MP4 (CRF 22, yuv420p, fast start) and VP9 WebM (CRF 32).
- Exported frame 7 as a WebP poster. CSS supplies restrained warmth and dimming.

Playback repeats the 1.7-second finite sequence. The final-to-first transition
is an editorial restart, not a claim of physical periodicity or a seamless
observation. No reverse playback, generated intermediate frames, or artificial
wave patterns are used. Reduced-motion, forced-color, and data-saving preferences
disable video loading; the still image supplies the fallback. A footer control
lets visitors pause the movie, and hidden tabs pause playback.
